# 🐍 Snake Game

A simple Snake game built with **Python** and **Pygame** as my first hands-on Pygame project.

This project was built while learning Python by actually making things instead of only following tutorials.

## 🎮 Features

- 🐍 Grid-based snake movement
- 🎮 Arrow-key controls
- 🍎 Random apple spawning
- 📈 Score system
- 🐍 Snake grows when eating apples
- 🚫 Prevents instant direction reversal
- 💀 Self-collision detection
- ☠️ Game Over state
- 🧱 Wall collision

## 🛠️ Built With

- Python 3.13
- Pygame 2.6.1

- This is just a small project I made while learning Python and Pygame.
Still learning, still building, still breaking things and fixing them.
